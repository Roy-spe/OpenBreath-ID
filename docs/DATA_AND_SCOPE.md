# Data access and scope

Obtain recordings from the [original study](https://github.com/TimnaSoroka/identification_paper/tree/code)
under its applicable terms. This repository contains code, aggregate results,
figures and synthetic examples—not recordings, participant assignments,
trial-level scores or checkpoints.

Local preparation reconstructs the primary partitions from the provider's labels.
Generated assignments and run artifacts belong in the ignored `private/`
directory; do not upload them manually. Repeat-session identity mappings are
not included. The classical feature extractor and dependent fusion code remain
unavailable pending redistribution permission.
